# fake-repo-for-pr-managment

Fixture repo for [dispatch-board](https://github.com/shayke-cohen/dispatch-board).

Its pull requests are parked on purpose, one per state the board classifies, so
the classifier can be checked against states that were *asked for* rather than
states that happened to exist. Nothing here is real work.

Reseed with `scripts/seed-fixture-repo.sh` in the dispatch-board repo.
